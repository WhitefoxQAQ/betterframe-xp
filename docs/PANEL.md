# パネルに載せる情報の案（公開版）

今のパネル（`panel/src/panel_main.cpp`）は、スライダー 10 本、トグル 8 個、プリセット 5 つ、負荷表示。**何が効いているか・今どういう状態かが画面から分かりにくい**ので、公開版では「状態 → 基本操作 → 詳細 → 負荷」の順に整理する案。**まだ実装していない**。

## 今のパネルの問題

| 問題 | 内容 |
|---|---|
| 状態が見えない | レイヤーが読まれているか、今のフレームに効果が掛かっているか（映像を検出しているか）が分からない。見えるのは「計測値がありません」だけ |
| 設定が並列 | 効くと確認済みの `sharpenAmount` と、未検証の `grain*` `deband*` が同じ重みで並ぶ |
| 説明が 1 行 | `desc` は各スライダーの短い説明だけ。「いつ使うか」「上げるとどうなるか」「重さ」が無い |
| 方式のトグルが専門的 | 「十字だけ読む / 明るさだけ / 四隅を省く」は、使う人が選ぶ理由がない |
| 再起動が必要なことを出さない | レイヤー本体の更新は SteamVR の再起動が必要なのに、パネルは何も言わない |

## 案: 4 つの区画

### 1. 状態（一番上、常に表示）

| 表示 | 出どころ | 意味 |
|---|---|---|
| レイヤー: 読み込み済み / 未読み込み | `stats` の更新時刻が 3 秒以内か（今の `valid` と同じ） | 未読み込みなら「SteamVR の再起動が必要」を出す |
| 今のフレーム: 効果あり / 素通し | `stats` の `gpuMsAvg`（約 1.0 ms 以上なら効果あり）。**将来**: レイヤーが `effectOn` を `stats` に書く | PC の映像が出ているか |
| 掛けている範囲: 全フレーム / PC の映像だけ | `streamOnly` | 今の動作モード |
| バージョン | レイヤーが `stats` に `version` と lib の sha 先頭 8 桁を書く（**要追加**） | 報告するときに使う |

> 「今のフレームが効果あり」は今も `gpuMsAvg` で推測できるが、1 秒平均なので切り替わりが見えない。レイヤーが `effectOn`（直近のフレームで効果を掛けたか）と `videoOnScreen` を `stats` に 1 行ずつ書くのが確実（数行の追加）。

### 2. 基本操作（既定で開いている）

| 部品 | キー | 説明文の案（パネル内に小さく） |
|---|---|---|
| 大きなスイッチ「効果」 | `enabled` | 全体の入/切 |
| スイッチ「PC の映像だけ」（実装済みのパネルでは右上） | `streamOnly` | ON 推奨。ホーム・ダッシュボードは素通し。OFF にすると Frame 単体のときも掛かるが、Frame 単体でダッシュボードを選ぶと映像が乱れる（パネルに注意を出している） |
| スライダー「シャープ」 | `sharpenAmount` | 0 で無効。1 を超えると縁が白黒に縁取られる |
| スライダー「鋭さ」 | `sharpness` | 効きの強さ。上げるとノイズも目立つ |
| スライダー「中心の範囲」「周辺の強さ」 | `centerRadius` `edgeAmount` | 目の中央は全力、周辺は弱める |
| ボタン「左右比較」 | `showSplit` | 各目の右半分だけに掛けて見比べる |
| プリセット | — | 「標準」「強め」「効果なし」の 3 つ（今の「暗部重視」「草・地面」は下の詳細の値に依存するので外す） |

### 3. 詳細（折りたたみ、既定は閉じる）

「未検証」と明記して並べる: `deband*`（3 本）、`detailBoost`、`grain*`（3 つ）。軽量化の 3 つ（`casCross` `casLuma` `cornerSkip`）は残すことにした（実装済みのパネルでは、画質タブの「シャープ」段落の副設定。詳細タブは廃止した）。

| 項目 | 説明文の案 |
|---|---|
| デバンド | 暗部や空の色の段差をなめらかにする（未検証） |
| ディテール重視 | 草や地面の模様が残る所だけ強くシャープにする（未検証） |
| グレイン | 細かい粒で、圧縮ののっぺり感を隠す（未検証） |

### 4. 負荷と診断（下、見えているときだけ 1 秒おきに更新）

| 表示 | 出どころ | 今 | 公開版で |
|---|---|---|---|
| レイヤーの GPU ms（平均 / 最大） | `stats` | ある | 残す。フレーム予算に対する割合（6.94 ms の何 %）も出す |
| 遅れたフレーム数（直近 1 秒の `gapLate`、`gapMsMax`、`gapMsP99`） | `stats`（出力済みでパネルが読んでいない） | **ない** | **追加**。レイヤーのせいか分かりやすくなる |
| fps | `stats` | ある | 残す |
| レイヤーの CPU µs | `stats` | ある | 折りたたみの中へ |
| GPU 全体の使用率とクロック | DRM fdinfo と devfreq | ある | 残す（`gpu_usage.*`） |
| パネル自身の CPU | `getrusage` | ある | 診断として小さく |

## パネルに出さないほうがよいもの

- `pcvrOnly`（廃止済み）と `splitEyes`（公開版では設定として出さない。レイヤー内部の既定 1 のまま）
- 生のパス・ログ（診断は `betterframectl stats` とログに任せる）

## 実装の見積もり

| 変更 | 範囲 |
|---|---|
| レイヤーが `stats` に `version`、`effectOn`、`videoOnScreen` を書く | `frame_stats.cpp` `effect_postfx.cpp` に数行ずつ |
| パネルの区画の組み替え、折りたたみ | `panel_main.cpp`（392 行）の描画と当たり判定 |
| 遅れたフレームの表示 | `params.cpp` の `readLayerStats` に `gapLate` `gapMsMax` `gapMsP99` を足し、`drawLoad` に 1 行 |
| 説明文を英語併記にするか | 公開の言語を決める（今のパネルは日本語のみ） |
| 再起動が必要な旨の表示 | レイヤーのバージョン（上）と、インストール済みの lib の sha を比べる |

レイヤーを変えると SteamVR の再起動が要るので、パネルの組み替えとまとめて 1 回で確認するのがよい。

## ブラウザで文言と配置を確認する（`panel/tools/panel_preview.py`）

ヘッドセットを被らずに、パネルの文言・段落・スイッチの並びを見るための道具。Frame も SteamVR も要らない。

```sh
python panel/tools/panel_preview.py                       # 既定: contrib/params.conf の値で tmp/panel-preview.html を作る
python panel/tools/panel_preview.py --params 自分の.conf --out 出力先.html
```

Orca のターミナルから使うときは `--open` を付けると、作ったあと Orca 内ブラウザで開く（`orca` CLI を使う）。同じタイトルのタブが開いていれば、新しいタブを増やさず再読み込みする。`--tab 2` で最初に開くタブを選べる（画質 = 0、実験的 = 1、SteamVR 設定 = 2）。`orca` が無い・Orca が動いていないときは警告だけ出し、HTML は作られる。

```sh
python panel/tools/panel_preview.py --open --tab 1
```

- `panel/src/params.cpp`（スライダーの名前・説明・範囲・プリセット）と `panel/src/panel_main.cpp`（段落の見出し・スイッチ・座標・Tips）を**読んで**、同じ文言と座標で SVG にする。文言を二重に管理しない。
- ブラウザで開くとタブをクリックで切り替えられる（`#1` などを URL に付けると最初に開くタブを選べる）。操作はできない（見るだけ）。
- **目安であって実機の描画ではない。** 文字の幅は見積もり（全角 = 文字サイズ、半角 = 0.56 倍）で、実機の Noto Sans CJK と数 % ずれる。はみ出し・重なりの警告はこの見積もりによるので、出たら Frame で `betterframe-xp-panel --render-png` を使って確かめる。
- 描画の仕方を写してある部分（スライダー 1 本の中身、タブの形、負荷カード）は、`panel_main.cpp` を変えたらスクリプトも合わせる。負荷カードの中身（実測値）は出ない。
- 状態で出し分ける文言（SteamVR に繋がらない / 書き込みに失敗）は出さない。
